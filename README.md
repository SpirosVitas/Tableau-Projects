## Data Analytics & BI Portfolio — Tableau Projects

A collection of interactive Tableau dashboards spanning operations, 
demographics, and workforce analytics, built to demonstrate end-to-end 
data visualization skills — from raw dataset to decision-ready dashboard. 
Published live via GitHub Pages with embedded Tableau Public 
visualizations.

**Live portfolio:** [spirosvitas.github.io/Tableau-Projects](https://spirosvitas.github.io/Tableau-Projects/index.html)

### New York City Parks
**Category:** Public Data · Geospatial Analysis

An interactive visualization of New York City's park system, built to 
explore public parks data geographically and support pattern discovery 
across the city's green spaces.

**Skills demonstrated:** working with public municipal datasets, 
geospatial visualization, and building an exploratory tool for 
location-based data.

[View dashboard](https://spirosvitas.github.io/Tableau-Projects/new-york-city-parks.html)

---

### Coal Terminal Maintenance Analysis
**Category:** Operations · Maintenance Analytics

An operations dashboard analyzing maintenance activity at a coal 
terminal, surfacing patterns in equipment upkeep and maintenance workload 
to support more proactive operational decision-making.

**Skills demonstrated:** industrial/operations data analysis, dashboard 
design for maintenance and reliability metrics, translating maintenance 
logs into an interactive decision-support view.

[View dashboard](https://spirosvitas.github.io/Tableau-Projects/coal-terminal-maintenance-analysis.html)
